Cognitive Modeling of Code Readability: Working Memory and Semantic Recoverability MEng Thesis

My MEng thesis, supervised by Prof. Earl T. Barr, proposes CognaScore and PreFixScore: complementary cognitive models of code readability based on working-memory load and semantic recoverability, evaluated at both function and file level.

Author: Tairan Wang

When Specifications Conflict: A Symmetry-Based Framework for Measuring LLM Preferences arXiv

A symmetry-based framework for analysing how LLMs resolve competing task specifications, evaluated on 550 executable conflict instances across 11 mathematical function families and extended to Boolean algebra, code generation, and clinical-rule settings.

Authors: Tairan Wang, Liang Zhou, Zikang Zhan, Pingchuan Yan

Artificial Intelligence Specification Conflicts LLM Preferences

HoarePrompt: Structural Reasoning About Program Correctness in Natural Language ICSE 2026 Distinguished Paper Award

Recipient of the ACM SIGSOFT Distinguished Paper Award. A framework for verifying program correctness from natural-language specifications using Hoare triples, strongest postcondition calculus, and k-induction for reasoning about loops.

Authors: Dimitrios Stamatios Bouras, Yihan Dai, Tairan Wang, Yingfei Xiong, Sergey Mechtaev

Software Engineering Program Verification LLM Reasoning
